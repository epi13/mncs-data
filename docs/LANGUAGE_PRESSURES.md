# MNCS language pressure ledger

Record workload, observed behavior, desired behavior, reproducer, owning layer, workaround and closure verification.

## Initial pressure targets

- record/structural typing and schema reflection
- ergonomic nullable/missing/error values
- lambda shorthand and type inference in pipelines
- generic iterators, streams and lazy transforms
- heterogeneous JSON-like values without abandoning type safety
- Unicode and date/time primitives
- efficient parsing and zero/low-copy byte-to-text boundaries
- columnar memory layout and vectorized operations
- joins/grouping and hash/equality contracts
- bounded-memory streaming
- schema evolution and coercion diagnostics
- concise error propagation with row/field context
